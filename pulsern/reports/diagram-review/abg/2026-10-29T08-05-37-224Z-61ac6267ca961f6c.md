### 1. [blocker · clinical] The metabolic-alkalosis band can falsely favor a mixed disorder

- **Problem:** For pH 7.48, PaCO₂ 50, HCO₃⁻ 36, the code expects PaCO₂ 44.2–48.2 and favors metabolic alkalosis plus respiratory acidosis 'rather than a single compensated one.' ### 2. [blocker · clinical] The compensation equation is extrapolated beyond usual physiologic limits

- **Where:** abg.jsx: INTERPRETED.hco3 and metabolic-alkalosis compensationLimit(); fact 8 · confidence medium
- **Problem:** The supported input pH 7.59, PaCO₂ 65, HCO₃⁻ 60 is internally consistent and receives a single partially compensated metabolic-alkalosis verdict: the code explicitly calls PaCO₂ 61–65 expected compensation. Respiratory compensation for metabolic alkalosis usually does not raise PaCO₂ beyond approximately 55–60 mmHg. Higher values warrant concern for an additional respiratory process, not an unqualified endorsement of compensation. That ceiling is approximate, not an absolute diagnostic cutoff.
- **Fix:** Constrain automatic interpretation to the validated domain of the selected compensation rule. At extreme values, return a qualified interpretation requiring history and assessment for an additional respiratory disorder instead of extending the linear equation indefinitely.

### 3. [major · pedagogy] An acute-to-chronic envelope is presented as evidence for a single disorder

- **Where:** abg.jsx: respiratory compensationLimit(), fits.length === 1 branch, mixedPossible: false · confidence high
- **Problem:** At pH 7.28, PaCO₂ 60, HCO₃⁻ 27, the function returns partially compensated respiratory acidosis with mixedPossible=false. HCO₃⁻ 27 fits the acute estimate, but not the chronic estimate of approximately 32 ± 2. In an established chronic respiratory-acidosis scenario, the same gas suggests an additional metabolic acidosis. Pooling both estimates hides that distinction; the abnormal-pH verdict does not tell the student that its interpretation depends on chronicity.
- **Fix:** Evaluate and display acute and chronic fits separately. Accept confirmed chronicity when available; otherwise state which interpretation fits and that mixed-disorder assessment remains history-dependent. Do not set mixedPossible=false solely because the pooled envelope contains the value.
