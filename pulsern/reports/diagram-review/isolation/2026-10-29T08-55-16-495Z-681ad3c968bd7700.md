### 1. [blocker · clinical] Congenital rubella can incorrectly select Droplet

- **Where:** isolation.jsx: CONDITIONS rubella entries and precautionFor() · confidence high
- **Problem:** precautionFor("A newborn has congenital infection caused by rubella virus.") returns droplet precautions. The congenital entry recognizes only the adjacent phrase "congenital rubella"; the generic rubella entry then defaults to acquired disease. This labels surgical-mask precautions as needed while failing to select Contact.
- **Fix:** Use structured congenital/acquired status, or abstain when the form cannot be established. Recognize congenital status beyond one exact adjacent phrase. Add this input as a regression test expecting Contact or null, never Droplet.

### 2. [blocker · clinical] Later-sentence treatment status is ignored

- **Where:** isolation.jsx: unsettled(), currentMatch(), precautionFor() · confidence high
- **Problem:** precautionFor("The client has head lice. Effective treatment was completed 48 hours ago.") returns Contact and produces "Needed for this client." Treatment cues are checked only in sentences naming a recognized condition, so the second sentence is ignored. This contradicts the diagram's own 24-hour discontinuation rule. The same defect affects resolution information for other infections.
- **Fix:** Resolve treatment and resolution status across the relevant client narrative before asserting current precautions. Prefer structured condition/status inputs; otherwise return null when a later sentence may change applicability. Add split-sentence regression cases.

### 3. [major · consistency] The displayed cohorting rule drops the compatibility requirement

- **Problem:** Fact 2 requires compatible additional precautions, but the picture and narration reduce eligibility to having the same pathogen. - **Fix:** Keep the qualification in the visible rows, captions and narration: cohort only with the same pathogen and compatible concurrent infection/precaution status, considering roommate risks. Do not leave this condition solely in the facts or SVG description.

### 4. [major · clinical] Varicella transport teaching omits covering lesions

- **Fix:** Add the lesion-covering requirement to the transport panel and narration. State that the client wears a surgical mask if tolerated and that affected varicella/zoster lesions are covered during essential transport.
