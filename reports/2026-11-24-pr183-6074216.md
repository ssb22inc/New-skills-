## Findings

### 1. [major] Question navigation no longer stays accessible on long items

- **Where:** `pulsern/src/App.jsx:2964` · confidence high
- **Problem:** The shipped .q-nav-wrap rule changes position:sticky to position:static for both practice and case-study navigation. This removes the existing sticky behavior despite the component's default layout="sticky" and the adjacent documentation explicitly promising that long content will not bury the controls.
- **How it fails:** On a phone, a long NGN item or expanded rationale puts Back, Skip, Next, and Review skipped below several screens of content. Students must now scroll to the bottom to move between items, whereas those controls previously remained above the tab bar.
- **Fix:** Preserve sticky navigation and fix the overlap separately, using appropriate clearance or a dedicated navigation region. Add a browser test with a long item and expanded feedback that checks both navigation visibility and Check answer accessibility.

### 2. [major] A collapsed usable band can place the toolkit over the tab bar

- **Where:** `pulsern/src/float-pos.js:31` · confidence medium
- **Problem:** band() forces maxY to top even when there is insufficient room for a full-size button. findClearSpot() can consequently accept a 52px button extending past view.bottom. Header and tab-bar rectangles are only added on the parking fallback, so they cannot reject this full-size placement.
- **How it fails:** A short landscape layout viewport, such as a browser that resizes its layout viewport when the keyboard opens, can produce view={vw:844,vh:130,top:70,bottom:54}. With no content blockers in the outer screen margin, findClearSpot() returns a full-size button spanning y=70–122, directly over the bottom navigation. The placement calculation is reproducible from the supplied code; keyboard viewport behavior was not browser-verified.
- **Fix:** Treat a usable band shorter than the button as having no full-size candidate. Use the chrome-guarded fallback or temporarily hide the floating control, and test both a too-short band and top greater than bottom.
