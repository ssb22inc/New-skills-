## Findings

### 1. [blocker] A false script closing tag still hides executable changes

- **Where:** `pulsern/ops/astra-review.mjs:132` · confidence high
- **Problem:** The raw-text scanner stops at any occurrence of `</script`, including `</scriptx>`, which does not close a script in HTML. Subsequent JavaScript is incorrectly treated as ordinary text and whitespace-normalized.
- **How it fails:** Change `<script>/* </scriptx> */ // disabled alert(1)</script>` to `<script>/* </scriptx> */ // disabled\nalert(1)</script>`, with an actual newline. The browser executes alert only in the second version, but pageDigest produces identical output. collectChanges consequently sends '(no textual change)' and attaches no full page, hiding the executable change from the reviewer.
- **Fix:** Recognize actual HTML raw-text closing tags, including the required delimiter after the tag name, or use a lossless representation instead. Add this example as an end-to-end collectChanges regression and require the newly executable code to appear in the review input.

### 2. [blocker] Speech tokenization equates .45 with 45

- **Where:** `pulsern/ops/narrate-lib.mjs:164` · confidence high
- **Problem:** Removing leading periods from every token deletes a meaningful decimal point. The exact-word check therefore treats `.45` and `45` as equal, while the remaining character-similarity check tolerates that one-character difference.
- **How it fails:** For the ABG lungs narration, a transcript that says 'a PaCO2 above .45' instead of 'a PaCO2 above 45' produces the same speech tokens and remains well above 0.92 similarity. audioCheck approves the hundredfold threshold error, allowing narrate.mjs to publish the recording.
- **Fix:** Parse numeric tokens without discarding decimal points; canonicalize `.45` to `0.45`, not `45`. Add positive and negative tests for leading-decimal notation using the actual narration, and bump QA_VERSION so earlier approvals are rechecked.

### 3. [blocker] Mutation tests use transcripts that already fail before mutation

- **Where:** `pulsern/tests/narrate.test.js:90` · confidence high
- **Problem:** asTranscribed joins only hyphens after a single letter. It converts `D-five-W` into `d5 w`, whereas speechTokens correctly expects `d5w`. The number-change and clinical-term mutation tests then reject this pre-existing token mismatch rather than necessarily detecting their intended mutation.
- **How it fails:** For tonicity/dextrose, audioCheck(script, asTranscribed(script)) already returns false without changing any number or clinical term. The parameterized corruption tests still pass, falsely claiming those mutations were tested. The later hand-written positive fixtures exercise a different transcript and do not repair this assertion.
- **Fix:** Assert that each unmodified transcript passes before applying its mutation. Use independently written faithful fixtures for these cases, or correct the converter and validate every generated baseline before testing corruption.

### 4. [major] Bot output commits request Astra but never run the publication tests

- **Where:** `.github/workflows/pulsern-diagram-map.yml:118` · confidence medium
- **Problem:** The explicit follow-up dispatch invokes only pulsern-astra-review. GITHUB_TOKEN pushes do not trigger pulsern-ci, so the emitted SHA never runs diagram-gate.test.js or the narration manifest checks. The same omission exists in the diagram-review and narrate workflows.
- **How it fails:** A mapping run starts against drawing key K1, a drawing-only edit K2 lands while it runs, and the save step rebases its K1 map onto K2. The new source-key test would reject that commit, but no CI run is scheduled for it. The browser content fingerprint does not detect drawing-only changes. If CI is required, the PR instead remains blocked awaiting a check that never starts; the live protection configuration was not available to verify which outcome applies.
- **Fix:** Explicitly schedule CI for each pushed head in all three workflows and require its result before merge. Validate the final rebased tree, not merely the tree on which generation began.
