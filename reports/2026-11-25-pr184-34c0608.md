## Findings

### 1. [blocker] Unresolved correct legacy rows do not block re-serving the same question as new, so XP/ability are counted twice

- **Where:** `pulsern/src/question-review.js` · confidence high
- **Problem:** `historyIndex` puts rows with `unclassified: true` into `idx.unresolved`, and migration 020 produces such rows whenever a legacy row matches both bank and built-in identities with the same category. `unseenQuestions` only blocks `idx.unresolved` for incorrect rows with more than one peer (`correct === false && peers > 1`), and `settledResult` never consults `idx.unresolved` at all. A catalog question with that raw id therefore has `settled.state === "none"`, is offered as new, and `answerXp` cannot see a canonical match because the old row remains unclassified.
- **How it fails:** A saved blob contains `log: [{ id: 7, correct: true, unclassified: true, key: null }]` after ambiguous relabeling. The catalog contains bank question 7 (`source: "bank", key: "bank:7"`). `unseenQuestions` returns bank 7; answering it again pays `10 * diff` and increments ability `n`, readiness, daily count, and review history even though the student already answered that question correctly. There is also no resolution UI for correct unresolved rows, so the ambiguity never gets repaired.
- **Fix:** Make any unresolved raw id block the corresponding catalog questions from `unseenQuestions`/new-question selection until it is resolved, and make `settledResult` return `pending` for such rows. Offer resolution for unresolved rows regardless of `correct`, or mark them seen by canonical identity once a catalog match is established.

### 2. [major] Protected feature label changed

- **Where:** `pulsern/public/product/pulsern-today-dashboard.png` · confidence high
- **Problem:** The updated dashboard shows a task labeled 'Fix a miss' instead of the protected 'Review Misses' label.
- **How it fails:** Students see a renamed feature, violating the requirement not to rename the protected 'Review Misses' feature.
- **Fix:** Change the label back to 'Review Misses'.
