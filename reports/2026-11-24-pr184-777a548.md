## Findings

### 1. [blocker] Guest recap promises Day 1 for trials that import a multi-day streak

- **Where:** `pulsern/src/guest.jsx:132` · confidence high
- **Problem:** SaveProgress hard-codes "Day 1" in both the recap statistics and the carry-over list. AuthScreen repeats the same claim. However, guest answers retain their local study days, and mergeGuestIntoBlob advances the streak for each eligible day. The existing across-midnight unit test explicitly demonstrates an imported streak of 2.
- **How it fails:** A visitor answers some trial questions before local midnight and finishes after midnight. The trial recap and signup screen report a Day 1 streak, but creating the account imports Day 2. The displayed progress being promised is not the progress the code actually transfers.
- **Fix:** Derive the guest streak using the same local-day progression rules used by the handoff, and share that result between SaveProgress and AuthScreen. Add a rendered cross-midnight test that checks the preview against the imported streak.

### 2. [major] Difficulty 3 does not distinguish a bank answer from a legacy case step

- **Where:** `pulsern/src/rewards.js:160` · confidence high
- **Problem:** sameAnswer treats any unsourced difficulty-3 row in the same category as a legacy case answer when its numeric ID matches. QBank answers recorded by the updated App still normally have no source, so this misclassifies newly recorded bank answers too. The regression test checks only a difficulty-1 bank collision and misses this case.
- **How it fails:** A student correctly answers bank question 101 at difficulty 3 in Physiological Adaptation, then correctly answers the sepsis case's second step. That step has legacy alias 101, so answerXp returns "repeat" and awards no XP even though the student has never answered that case step.
- **Fix:** Record an explicit QBank source and exclude those rows from legacy case matching. Do not classify ambiguous historical rows as case answers solely from difficulty and category. Add a regression test using a difficulty-3 bank answer with the same ID and category as a case alias.
