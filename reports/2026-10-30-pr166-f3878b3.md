## Findings

### 1. [blocker] Preserve the clinical abbreviation IE instead of equating it with 'that is'

- **Where:** `pulsern/api/_speak.js:155` · confidence high
- **Problem:** The case-insensitive regex permits both dots to be absent, so it matches bare uppercase IE (infective endocarditis). It canonicalizes that diagnosis abbreviation and the spoken phrase 'that is' to the same token. An incorrectly expanded diagnosis can therefore pass the exact-word audio gate.
- **How it fails:** For the script 'The nurse assesses a client with IE for embolic complications.', a transcript of 'The nurse assesses a client with that is for embolic complications.' produces exactly the same canonical text and clinical-unit sequence. voiceCheck accepts the take even though the diagnosis abbreviation was spoken incorrectly.
- **Fix:** Distinguish explicit i.e. notation from the undotted clinical acronym IE; do not apply this equivalence indiscriminately with case-insensitive optional punctuation. Add a negative regression test showing that IE versus 'that is' fails, alongside positive tests for supported i.e. spellings.
