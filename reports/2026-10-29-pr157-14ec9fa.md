## Findings

### 1. [blocker] Unrestricted compound joining erases clinical distinctions

- **Where:** `pulsern/ops/narrate-lib.mjs:276` · confidence high
- **Problem:** Joining any two alphabetic tokens treats clinically different expressions as spelling variants. For example, "a febrile" becomes "afebrile", and "a septic" becomes "aseptic". The similarity threshold does not protect these distinctions because only one space differs.
- **How it fails:** audioCheck("A febrile client requires further assessment for a possible infection.", "Afebrile client requires further assessment for a possible infection.") returns pass=true: joinCompounds removes the mismatch and similarity remains above 0.92. A recording that changes whether the client has a fever can therefore be signed and published.
- **Fix:** Replace unrestricted concatenation with explicitly vetted compound equivalences, such as meal-time/mealtime and iso-osmolar/isoosmolar. Add passing-baseline and rejecting-mutation tests for a febrile/afebrile and a septic/aseptic. Bump QA_VERSION when tightening the gate so existing clips are rechecked.

### 2. [major] Compound equivalence is absent from the similarity check

- **Where:** `pulsern/ops/narrate-lib.mjs:282` · confidence high
- **Problem:** wordMismatch compares joined compounds, but speechSimilarity still compares the original token spacing. Consequently, a spelling difference explicitly accepted by the new rule can still fail audioCheck. The added test uses a long script, which dilutes this discrepancy below the threshold.
- **How it fails:** audioCheck("Iso-osmolar.", "Isoosmolar.") produces mismatch=null but similarity=10/11, below 0.92, and rejects the faithful transcript. Likewise, "Pre-load and after-load." versus "Preload and afterload." fails at 21/23 similarity. Such clips exhaust both takes and stop the recording run despite containing the accepted equivalent words.
- **Fix:** After restricting compound equivalence safely, apply the same normalized token comparison to both wordMismatch and speechSimilarity. Add short-script and multiple-compound tests so acceptance does not depend on unrelated narration length.
