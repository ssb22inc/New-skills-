### 1. [major] Compound matching compares raw spellings against normalized tokens

- **Where:** `pulsern/ops/narrate-lib.mjs:284` · confidence high
- **Problem:** scriptCompounds stores raw pairs, but foldCompounds receives tokens already changed by plural stripping and unit aliases. Consequently, some hyphenated compounds never match their pair entry, contradicting the new open/closed-compound behavior.
- **How it fails:** audioCheck("Non-smokers still need routine screening.", "Nonsmokers still need routine screening.") returns pass:false. The stored pair is "non smokers", while the script tokens are "non smoker" and the transcript token is "nonsmoker". If transcription consistently uses the correct closed spelling, both takes fail and recordAll stops the run despite faithful audio.
- **Fix:** Construct compound aliases in the same normalized representation used for comparison, accounting for both the open tokens and the normalized closed spelling. Add a regression proving that hyphenated, open, and closed forms of a plural compound pass while a changed clinical word still fails.
