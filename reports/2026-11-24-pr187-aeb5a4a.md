## Assessment

The routing and stricter JSON parsing generally fail closed. However, the new text/vision reviewer split is not consistently reflected in audit records, so image reviews can be attributed to DeepSeek when Sol actually handled them.

## Findings

### 1. [major] Save the selected image reviewer before starting the paid call

- **Where:** `pulsern/ops/astra-review.mjs:650` · confidence high
- **Problem:** The failure checkpoint is saved before reviewerFor() selects the vision model. At that point, report.model is still REVIEW_MODEL (DeepSeek). The subsequent assignment to Sol exists only in memory until the request returns and another save occurs.
- **How it fails:** A PR changes a PNG and the runner is killed or times out while awaiting the Sol request. The surviving Markdown and raw JSON checkpoint incorrectly identify DeepSeek as the reviewer, leaving no accurate record of which model received the paid request.
- **Fix:** Select and cross-family-check the model, assign report.model, and then save the pre-call checkpoint. Add an image-review test that inspects the saved checkpoint while the model call remains pending.

### 2. [major] Propagate the actual reviewer to publication provenance

- **Where:** `pulsern/ops/review.mjs:65` · confidence medium
- **Problem:** review() now selects Sol for images but returns only the response text. Meanwhile, the supplied content-gate test still requires publishing scripts, including seed-visuals, to persist review_model: REVIEW_MODEL, which now means DeepSeek. That assertion no longer establishes that the recorded model actually performed the review. The publisher implementations were not supplied, so I could not verify which publishing calls currently provide images.
- **How it fails:** An image-backed item passes review(..., { images }) and is published through a caller retaining review_model: REVIEW_MODEL. Sol performed the review, but the published audit metadata names DeepSeek, and the existing provenance test passes despite the mismatch.
- **Fix:** Expose the actual reviewer identity alongside the review result and persist that identity in publication metadata. Replace the constant-matching provenance assertion with a runtime test covering an image review through publication.
