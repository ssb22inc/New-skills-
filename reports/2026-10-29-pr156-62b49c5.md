## Findings

### 1. [blocker] Two-digit potassium results are extracted as 1.0

- **Where:** `pulsern/src/diagrams/match.js:113` · confidence high
- **Problem:** The accepted range now starts at 1.0, but the K regex still captures only one integer digit and permits the match to stop before another digit. Consequently, extractPotassium("Potassium 10.0 mEq/L") returns { k: 1 }. Previously, the 1.5 lower bound rejected this truncated match.
- **How it fails:** A question reporting potassium of 10.0, 11.0, or 12.0 produces a pairing candidate showing severe hypokalemia instead of severe hyperkalemia. If accepted by pairing review, the worked diagram outlines the opposite lab category and teaches the wrong clinical interpretation. The new tests that render k = 10 directly bypass this extractor.
- **Fix:** Parse the complete numeric token, support the intended two-digit range, and reject partial numeric matches with an appropriate trailing boundary. Add extraction and proposePairs regression tests for 10.0, 11.0, 12.0, and out-of-range values.

### 2. [blocker] The no-client-outline test does not inspect the outline

- **Where:** `pulsern/tests/isolation.test.js:22` · confidence high
- **Problem:** The test checks only that the rendered HTML lacks "Needed for this client". The previous unsafe implementation drew a patient-specific dashed rectangle without ever emitting that phrase, so it would pass this assertion unchanged.
- **How it fails:** IsolationDiagram regresses to honoring params.types and outlines the airborne row for an unconfirmed or incorrectly attributed condition. The matcher tests can still pass because they exercise extraction separately, and this component test reports success despite the misleading clinical highlight.
- **Fix:** Assert that supplying legacy patient-specific params produces the same diagram as concept-only params, normalizing generated IDs if necessary, or explicitly inspect the rendered highlight geometry. Verify that restoring the previous params.types highlighting makes the test fail.
