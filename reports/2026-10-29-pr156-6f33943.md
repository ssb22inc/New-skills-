## Findings

### 1. [blocker] ABG extraction silently truncates decimal results

- **Where:** `pulsern/src/diagrams/match.js:39` · confidence high
- **Problem:** PACO2 accepts only integer digits, but its trailing word boundary permits a match immediately before a decimal point. Consequently, oneAsWritten records a truncated value with falsely asserted whole-number precision. HCO3 has the same prefix-matching problem when more than one decimal place is supplied. The new consistency check does not reliably reject these truncated gases.
- **How it fails:** extractAbg("pH 7.34, PaCO2 45.4, HCO3 23.7") returns PaCO2 45 with precision 0 rather than 45.4. That truncated gas passes abgConsistency. interpretAbg then reports an unresolved primary process because both non-pH values appear within reference ranges; interpreting the actual values identifies a respiratory acidosis pattern. This is also a supplied diagram text case, but the tests exercise direct parameters rather than extraction of that case.
- **Fix:** Match complete numeric tokens, preserving every supported decimal place. If a numeric representation is unsupported, reject the entire token rather than accepting its prefix. Apply this to all ABG patterns and add extraction-to-interpretation regression tests using decimal PaCO2 and multi-decimal HCO3 values.

### 2. [major] Insulin extraction does not enforce the diagram's subcutaneous route

- **Where:** `pulsern/src/diagrams/match.js` · confidence high
- **Problem:** The revised diagram explicitly models subcutaneous action and labels the worked result as regular U-100, but extractInsulin checks concentration and product without checking administration route. It therefore proposes a patient-specific subcutaneous peak window for explicitly intravenous insulin.
- **How it fails:** extractInsulin("Regular U-100 insulin was given intravenously at 0700.") returns {type:"short",givenAt:"07:00"}. The worked illustration and dynamic caption then give a 09:00–11:00 peak window using the subcutaneous 2–4-hour range, despite the question specifying IV administration. The separate comparison caption saying IV insulin acts faster does not correct that worked result. The downstream pairing reviewer might reject it, but the proposal itself is incorrect and no supplied test catches this route mismatch.
- **Fix:** Reject patient-specific extraction for IV administration and other unsupported routes, leaving the diagram concept-only, or carry and validate an explicit route before calculating a worked window. Add a regression test for explicitly IV regular U-100.
