## Assessment

Not ready to merge. Three safety defects remain: accepted raster files can conceal bytes from review, narration QA can approve a clinically meaningful omission, and rounded compensation bounds can reverse an ABG mixed-disorder label. This assessment is based on static inspection; I did not run the tests or verify GitHub environment settings.

## Findings

### 1. [blocker] Image-only review still omits accepted non-pixel payloads

- **Where:** `pulsern/ops/astra-review.mjs:252` · confidence high
- **Problem:** The PNG allowlist permits PLTE without checking whether its contents affect the rendered pixels. A truecolor PNG may legally contain an optional suggested palette that does not determine those pixels. Its bytes therefore pass the CRC and decompression checks but are never exposed to the reviewer as text. WebP has the same broader validation gap: only container boundaries are checked, not the encoded image payload. The new positive test even accepts a two-byte VP8L payload, shorter than its required header.
- **How it fails:** Insert a PLTE chunk before IDAT in an otherwise valid RGB PNG, containing a service-role key padded to a valid palette length, and calculate its CRC. isStrictPng returns true, collectChanges sends only the unchanged picture and a hash, and the secret can ship in a public asset without appearing in the review text.
- **Fix:** Require the shipped image bytes to use a validated canonical representation, or expose/reject non-rendered payloads explicitly. At minimum, reject suggested palettes in truecolor PNGs and validate WebP bitstream consumption rather than just RIFF sizes. Add regression tests using genuinely decodable images with concealed payloads, and replace the invalid WebP positive fixture.

### 2. [blocker] A clinically meaningful initial A is still discarded as a filler

- **Where:** `pulsern/ops/narrate-lib.mjs:168` · confidence high
- **Problem:** keepLetters protects A after selected words or inside a sentence, but not a blood-group A at the beginning of a sentence. speechTokens then removes it through FILLER. Consequently, the new exact-word gate still treats a changed blood-compatibility claim as faithful narration.
- **How it fails:** Compare the script "A positive packed red cells are ABO-compatible with an A positive recipient." with the transcript "Positive packed red cells are ABO-compatible with an A positive recipient." The token arrays are identical after the initial A is discarded, and similarity exceeds 0.92, so audioCheck passes. The recording now incorrectly generalizes compatibility to positive red cells of other ABO groups.
- **Fix:** Preserve clinically meaningful letter designations at sentence boundaries, including A positive/A negative blood groups, or stop discarding ambiguous articles during the publication check. Add this exact positive-baseline/omission regression and bump QA_VERSION so previously accepted clips are checked again.

### 3. [blocker] Rounded bounds can reverse the additional ABG disorder

- **Where:** `pulsern/src/diagrams/abg.jsx:65` · confidence high
- **Problem:** compensationLimit detects an out-of-range value using unrounded bounds, but secondDisorder determines its direction using the rounded expected array. A value below the actual lower bound can equal the displayed lower bound and consequently be classified as high, producing the opposite additional disorder.
- **How it fails:** interpretAbg({ ph: 7.52, paco2: 43, hco3: 34.3 }) calculates a metabolic-alkalosis compensation interval of approximately 43.01–47.01. It flags 43 as below that interval, rounds the interval to 43–47, then evaluates 43 < 43 as false. The student receives "Possible mixed: metabolic alkalosis + respiratory acidosis" even though the detected deviation was toward a lower PaCO₂, not a higher one.
- **Fix:** Return the low/high deviation directly from the comparison against the original bounds and use that direction to select the additional disorder. Apply a consistent clinically appropriate rounding/tolerance policy before classification; round separately for display. Add a regression for this supported decimal-bicarbonate input.
