## Findings

### 1. [blocker] Capitalized variables cause multiplication signs to be silently removed

- **Where:** `pulsern/src/read-aloud-script.js:73` · confidence high
- **Problem:** SEPARATED assumes a middle dot followed by a capital letter is a layout separator whenever the passage has no equals sign. Mathematical variables satisfy that rule too. For example, speakable("Calculate MAP using (SBP + 2 · DBP) / 3.") changes the multiplication dot into a comma. voiceable() then accepts the altered passage because the dot is gone. The subsequent transcription check compares against this altered script, not the approved source, so it cannot catch the missing multiplication.
- **How it fails:** An approved question, rationale, or flashcard contains a clinical calculation expressed with a middle dot and a capitalized variable, without '='. Listen can read a pause instead of multiplication while displaying the original formula, and the audio can pass QA.
- **Fix:** Do not infer that a middle dot is punctuation solely from capitalization. Preserve ambiguous dots so voiceable() refuses the passage, or restrict separator conversion to explicitly recognized non-mathematical contexts. Add regression tests for formulas such as '(SBP + 2 · DBP) / 3' and '2 mg/mL · Volume in mL', verifying that multiplication is either spoken explicitly or the passage is not voiced.
