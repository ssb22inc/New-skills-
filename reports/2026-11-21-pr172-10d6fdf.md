- **Where:** `pulsern/ops/read-aloud-worker.mjs:690` · confidence high
- **Problem:** `keepGoing = more || legacy.done === false` emits `more=true` whenever migration is unfinished, even when `runJob()` deliberately returns `more=false` because the daily budget is exhausted, provider credentials are invalid, repeated refusals indicate a setup problem, or an operational failure made no progress. - **How it fails:** The migration pauses after its time slice, then Polly returns 401. `runJob()` reports a setup failure and disables continuation, but the CLI writes `more=true` to GITHUB_OUTPUT anyway. A workflow honoring that output is instructed to relaunch against the same broken configuration. Exhausting the daily speech budget during an unfinished migration similarly requests immediate follow-up runs despite there being no capacity to voice anything.
- **Fix:** Combine unfinished-migration work with the normal work-remaining condition before applying the existing setup, budget, and failure/progress guards. Add tests for unfinished migration alongside budget exhaustion, setup failure, and failure without progress, as well as the healthy continuation case.
