## Assessment

Changes needed. Static review found a dashboard crash on shift completion and ineffective legacy-case repeat protection masked by an unrealistic test fixture. I did not execute the test suite.

## Findings

### 1. [major] Completing a shift crashes the Today dashboard

- **Where:** `pulsern/src/App.jsx:1785` · confidence high
- **Problem:** Monitor evaluates shiftCompleteNote({ missesOpen }) when shift.complete is true, but missesOpen is neither defined in Monitor nor received as a prop. The variable declared inside App is outside this component's scope.
- **How it fails:** A student clears the flashcard queue and completes eight questions with no outstanding miss requirement. Returning to Today renders the completed shift, throws ReferenceError, and replaces the dashboard with the error boundary.
- **Fix:** Pass missesOpen from App through Today into Monitor, and add a browser regression that completes a shift and returns to Today.

### 2. [major] Legacy case-repeat detection requires provenance that old saves never recorded

- **Where:** `pulsern/src/rewards.js:153` · confidence high
- **Problem:** The legacyAliases branch requires row.source === "case", but the pre-change record handler never persisted source. Consequently, actual legacy case answers cannot match this branch. The regression in tests/review3.test.js supplies source: "case" on its purported old rows, so it passes without exercising the save format being migrated.
- **How it fails:** A saved correct sepsis-case answer has id 101, its category, difficulty and correct outcome, but no source. After upgrading, answering that step again produces case-sepsis-1 and awards 30 first-answer XP rather than recognizing the earlier correct answer. An earlier miss likewise receives first-answer XP instead of the correction award.
- **Fix:** Test with the exact pre-change log shape. Establish an explicit migration or grandfathering policy for ambiguous legacy numeric IDs, retaining provenance for new records; do not claim legacy deduplication based on a field those saves never contained. Test genuine same-number bank answers alongside legacy case answers.
