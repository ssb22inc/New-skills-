## Assessment

Request changes. Two content-representation gaps remain in the review gate, and narration QA rejects ordinary faithful contractions. This was a static review; I could not run the tests or verify the GitHub environment and branch-protection settings.

## Findings

### 1. [blocker] Unparseable lockfiles hide their contents instead of failing closed

- **Where:** `pulsern/ops/astra-review.mjs:173` · confidence high
- **Problem:** lockDigest replaces every malformed JSON document—and every valid JSON scalar—with the same constant string. collectChanges neither rejects these files nor supplies their raw contents. Two different unparseable versions therefore produce an empty digest diff and reach the reviewer as "no textual change".
- **How it fails:** The lockfile classifier matches any in-scope path ending in package-lock.json, including pulsern/public/package-lock.json. Such a file can contain a credential or personal data while the reviewer receives only "UNPARSEABLE package-lock.json". Because this public file is not npm's actual lockfile, npm ci need not fail, and the ordinary successful model-response path can certify the change without inspecting the exposed content.
- **Fix:** Throw on an unparseable or unsupported lockfile shape so collection fails closed, or fall back to an exact raw-text diff. Add end-to-end tests showing that distinct malformed versions cannot disappear from the prompt and that a malformed public/package-lock.json cannot receive an unreviewed pass.

### 2. [blocker] Near-transparent pixels still carry bytes invisible to image review

- **Where:** `pulsern/ops/png-canonical.mjs:184` · confidence high
- **Problem:** The encoder clears RGB only when alpha is exactly zero. With a small nonzero alpha, it preserves many RGB values that render identically after 8-bit compositing or premultiplication. Canonical compression consequently does not establish the claimed one-to-one relationship between visible output and accepted bytes.
- **How it fails:** Encode printable credential bytes as the red channels of RGBA pixels [byte, 0, 0, 1]. The result passes isCanonicalPng and is sent to Astra only as an image. On an 8-bit white composite, red values below 128 all round to the same output value, so the image can look uniform while the downloadable PNG retains the credential in its decompressed pixel data. The new tests explicitly preserve low-alpha RGB but do not test this concealment path.
- **Fix:** Close this path by rejecting partial-alpha images at the review boundary, or by normalizing through a defined rendering representation that removes render-indistinguishable channel values. Keep conversion appearance-preserving, and add an independent-decoder regression using distinct low-alpha pixel payloads with identical rendered output.

### 3. [major] Affirmative contractions fail the promised speech normalization

- **Where:** `pulsern/ops/narrate-lib.mjs:227` · confidence high
- **Problem:** The contraction replacements do not expand affirmative contractions: "it's" becomes "its", and "they're" becomes "they re". These tokens cannot match "it is" or "they are", despite contractions being documented as accepted spelling differences.
- **How it fails:** audioCheck("It is given with a meal.", "It's given with a meal.") returns pass:false. The rapid-insulin narration uses this wording, so a faithful contracted transcription causes another paid take and can ultimately remove the clip from the manifest even though its clinical meaning is unchanged.
- **Fix:** Normalize supported affirmative contractions to equivalent full-word tokens, treating ambiguous possessive/'s forms separately rather than blindly deleting the apostrophe. Add literal positive and negative transcript tests for current narration, including "it is" versus "it's" and preservation of negations.
