## Findings

### 1. [blocker] Function-quota test ignores nested API routes

- **Where:** `pulsern/tests/vercel-functions.test.js:9` · confidence high
- **Problem:** The test uses readdirSync("api"), which inspects only immediate entries. A route file inside a subdirectory is not counted, even though nested API routes can be deployed as serverless functions. The test therefore does not establish that the deployment stays within Vercel's function limit.
- **How it fails:** If new endpoints are added under a path such as api/admin/status.js, the test can remain green while the deployed function count exceeds the Hobby limit, causing the deployment to fail or exceed its configured allowance.
- **Fix:** Recursively enumerate API route files using Vercel's actual function-discovery rules, and separately handle shared modules using a verified exclusion convention (or move shared modules outside api/). Add a test fixture with a nested route and assert it contributes to the count.
