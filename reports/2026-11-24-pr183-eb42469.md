### 1. [blocker] The question shortcut hint advertises unsupported digit controls

- **Where:** `pulsern/src/App.jsx:1795` · confidence high
- **Problem:** Every answering screen displays "Keys: 1–9 pick", but the pick handler only supports multiple-choice, select-all, and highlight items. Ordering, matrix, bow-tie, cloze, and calculation items ignore these shortcuts. The newly displayed instruction therefore promises behavior the code does not provide.
- **How it fails:** A student opens an ordering question and follows the displayed instruction by pressing the numbered choices. No entries are added to the order, and Enter cannot check the unanswered item. The existing shortcut tests exercise the key mapper, not its behavior for these item types.
- **Fix:** Render an item-type-specific hint that advertises only implemented shortcuts, or implement the corresponding digit interactions. Add browser coverage for the hint and behavior on an ordering item and the other unsupported types.
