## Findings

### 1. [blocker] Duplicate lockfile keys hide committed content from review

- **Where:** `pulsern/ops/astra-review.mjs:178` · confidence high
- **Problem:** lockDigest parses the file with JSON.parse before constructing its only review representation. JSON.parse silently discards earlier occurrences of duplicate keys. A changed lockfile can therefore contain newly committed sensitive content while producing an identical digest. Lockfiles receive neither a raw diff nor full-file context.
- **How it fails:** Prepend a duplicate top-level "name" property containing a credential before the existing "name":"pulsern" property. npm and lockDigest retain the latter value, so installation still works and the reviewer sees "no textual change", while the credential remains in the committed file. Duplicate keys inside package entries have the same problem.
- **Fix:** Detect and reject duplicate object keys at every nesting level before summarization, or include a lossless raw diff whenever parsing would discard source content. Add an end-to-end test proving that a duplicate-key payload cannot reach the model as an unchanged lockfile.

### 2. [blocker] Narration QA still discards a blood-group A at sentence start

- **Where:** `pulsern/ops/narrate-lib.mjs:171` · confidence high
- **Problem:** The filler filter removes every unprotected "a", but keepLetters does not protect a sentence-initial blood-group label followed directly by a product name. Consequently, the exact-word check can approve audio that changes a specific transfusion fact into a false general statement.
- **How it fails:** audioCheck("A plasma contains anti-B antibodies.", "Plasma contains anti-B antibodies.") passes: the initial "A" matches none of the protection patterns and is discarded as an article. Both sides then have identical tokens, similarity 1, and no mismatch. The accepted transcript incorrectly attributes anti-B antibodies to plasma generally, including AB plasma.
- **Fix:** Do not discard an ambiguous standalone A in clinical narration. Prefer retaining the token and failing closed over expanding an inevitably incomplete context allowlist. Add a faithful-baseline and dropped-label regression test for "A plasma", including lowercase transcription.
